# Portafolio Personal - React

Este proyecto es mi portafolio personal, una SPA estática:
- Selección de tema claro/oscuro, persistido en `localStorage` (favicon incluido).
- Sección "Desarrollo Fullstack": las fases reales de mi proceso de trabajo (análisis, diseño, programación, calidad, seguridad, despliegue).
- Carrusel de proyectos con imágenes, tecnologías y links a GitHub / sitio en vivo para los que son públicos.

🏗️ Arquitectura y Diseño

- Presentación (Frontend): React + Vite + Tailwind + TypeScript.
- Sin backend propio: es un sitio estático desplegado directamente en GitHub Pages.

🖥️ Frontend
- Framework: React con Vite y TypeScript.
- Estilos: Tailwind CSS.
- Iconos: lucide-react y react-icons.

## 🛠️ Tecnologías
- Frontend: React + Vite + TypeScript + Tailwind CSS
- Despliegue: GitHub Pages, CloudFlare para CDN y seguridad.
